# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## What this project does

toolkb-mcp is a local MCP server. It fetches only the URLs you ask for (YouTube, web pages, App Store reviews), needs no API key, and sends no data to any third-party service.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/jack-reson8/toolkb-mcp/security/advisories/new) instead of a public issue. Expect a first reply within a few days.
